# Gate log, 2026-10-19

The runbook (`gate-runbook.md`) run against the real publisher. Each step: what was run, what answered.
Keys and tokens are never written here.

## Setup

- Store: local Postgres, schema `gate_2026_10_19` (its own, so nothing of ME's is touched).
- Host: `node bin/crubal-host.ts serve --port 8787`, domain `gate.localhost`, `CRUBAL_HOST_OF` mapping
  `cashierfu.com` and `mediaencyclopedia.com` to `http://localhost:3100/h` (the Cashierfu app's host on the
  development machine, the adopter's publisher until cashierfu.com is deployed).
- Adopter's publisher: the app's host, after `scripts/publish-shipped.mts` published the 2026-11-11 set
  (bench, channels, commerce, operations, person, platform, product, stacks, storefront at 2026-11-11;
  location 2026-11-07; service 2026-10-16; mediaencyclopedia.com/media 2026-11-11), each signed with the
  owner's key the app's host holds.

## Steps

1. **Publisher.** `GET https://crubal.com/.well-known/crubal.json`: owner crubal.com, one Ed25519 key
   (from 2026-10-15), packages core 2026-10-14, units 2026-10-15, party 2026-10-16 with version URLs.
   `GET https://crubal.com/party/2026-10-16/package.json`: `crubal: 2`, id, version, owner, `hash`, **no
   `sig`**. The same for core and units. Finding: the site was built without `CRUBAL_SIGNING_KEY`.
2. **Host up.** `migrate` → `migrated`; `owner create gate.example` → the owner with its public key;
   `key issue gate.example gate.example` → one key, kept out of this log; `GET /health` →
   `{"ok":true,"domain":"gate.localhost",…}`.
3. **Install by name.** `POST /o/gate.example/install {"package":"cashierfu.com/product"}` as the owner →
   400 `crubal.com/party: unsigned bundles are refused; a store may allow them for development`. The host
   fetched the adopter's well-known file at the mapped URL, found product extends crubal.com/party and
   cashierfu.com/location, fetched party from crubal.com first, and refused it, correctly. The same for
   `mediaencyclopedia.com/media`. **Stopped here.**
4. to 8. Not run against the real publisher yet; each is exercised by `packages/crubal-host/test/host.test.ts`
   against a local publisher (install by well-known with dependencies first, project and serve, a form run, a
   send acted and answered, a tick, an erasure).

## What unblocks it

The steward sets `CRUBAL_SIGNING_KEY` (the private half of the key whose public half is in the well-known
file and `site/build.mjs`) in the crubal.com deployment's environment and redeploys. The build then prints
no `unsigned` warning and each bundle carries `sig`. Then steps 3 to 8 run again from this log's setup.
