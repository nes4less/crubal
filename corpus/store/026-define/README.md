# Definitions are transactions too (8.5, 11.4)

The owner's working package is built from `define` writes like the data is from value writes. L-1 defines a
facet and a class; L-3 is a review decision (the new value is added) and the `define` write it produced; L-4
retires the class. Rebuilding gives the definitions in force at the end beside the data, with no package
file outside the log.
